Offline Python / PyCharm

Connect the laptop to this same kit AP. Copy python_companion from the project ZIP to the laptop. Run pair_ap.py once and confirm the Device ID printed on your kit case. Then open main_ap.py in PyCharm.

Python and OpenCV run on the laptop. The kit provides the local API at 192.168.4.1; the drone does not execute uploaded Python files.
