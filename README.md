# ZEBJUS Aerion V18.3.83 — AP-only controller

The kit always starts its own access point, even when old router profiles are saved. SSID is the Kit Name and the default AP password is `12345678`. Connect both the Android phone and computer to the kit AP. Open the full WebApp locally with `python3 start_offline.py` (or use an already cached copy); the kit API is `http://192.168.4.1`. Allow local network access in the browser if prompted. Android provides physical joystick input; the paired WebApp can observe live input and start output-inhibited Tripod/Flight Training on that same AP. A fresh simulator run requires manual virtual ARM. Router/STA setup and switching are removed from the active workflow.

A1 is a Wi-Fi sensor bridge; A2/Aerion F1 supports MPU6050 Rate/Angle control. Physical flight and update on a device require hardware verification. Ensure the board profile matches before flashing. Previously committed 18.3.82 firmware images and APK are **not** V18.3.83; use only freshly built V18.3.83 artifacts. The firmware GitHub Action builds A1/A2 after a successful main push. Android signing needs the repository secret `AERION_DEVELOPMENT_STORE_PASSWORD` for the existing development certificate; until configured, the new APK cannot be delivered or installed over the old signed APK.

For assembly and offline classroom use, see [OFFLINE_START_HERE.md](OFFLINE_START_HERE.md). Release details are in [RELEASE_NOTES.md](RELEASE_NOTES.md).
