# FlightCore V18.3.47: each stage

This guide describes the A2/XIAO ESP32-C6 path in `FlightCore_Firmware/ZEBJUS_FLIGHTCORE.ino`. A1/ESP32-C3 still acts as a Wi-Fi and sensor bridge; its ESC pins are not validated.

| Stage | Firmware action | What the student sees / can change |
| --- | --- | --- |
| Boot and identity | Load saved Wi-Fi, Device ID, motor permutation, PPM edge/arm mode, PID and calibration from NVS. Detect the IMU. | Kit Connect and `/api/status` show the selected physical board and its expansion map. |
| Sensor and output setup | Configure MPU6050 ±8 g, ±500 dps and 400 kHz I²C; attach four ESC channels at 250 Hz and 12-bit resolution. Hold safe pulses, average 2000 gyro samples while level and still; reject noisy/failed calibration. | `flightReady` is a software prerequisite, not a flight-certification result. ESC calibration is an explicit prop-off action, not an automatic boot step. |
| AP/STA and receiver | Use stock ESP32 `WiFi.h`/`WebServer.h`; run AP setup or STA from saved credentials. Decode physical PPM on D6 and receive fresh verified local Web/AP/Python RC frames. Web frames take priority; PPM is fallback. | `/fly` provides AP/STA sticks and keyboard; WebApp Joystick, Tripod mirror and Python use the same RC frame API. `receiver_read` gives CH1–CH10, source and measured PPM/Web/loop Hz. No custom `WiFiReceiver.h` is required. |
| Arming | For physical PPM, default yaw right ≥1900 for 1 s arms and yaw left ≤1100 for 1 s disarms with throttle ≤1050 and roll/pitch within ±80 of center; choose CH5 switch as an alternative. Web/AP/Python use CH5. | Hardware I/O Studio and AP `/io` expose `ppm_config.armMode`, edge and reversals. At low throttle, 15 s with no meaningful CH1–CH4 change disarms. |
| 250 Hz sampling | The scheduler aims for 4000 µs per control pass. Read 14 bytes of MPU6050 gyro/accel, subtract stored gyro bias and accelerometer offsets, calculate tilt, fuse roll and pitch in separate 1D Kalman updates. | `attitude_read`, IMU charts and calibration show the filtered values even while disarmed. Measured `flightLoopHz`, overruns and gap help detect missed deadlines. |
| Flight mode and PID | CH6 low uses Angle: target angle → outer angle PID → desired roll/pitch rates → inner rate PID. CH6 high uses direct Rate PID. Yaw always uses rate PID. PID outputs and integrators are bounded; low throttle resets integrators. | Settings, PID page and Python `pid_get`/`pid_set` expose persistent parameters. Defaults match the supplied rate gains; stored user tuning remains until Reset Defaults. Changing mode while armed disarms. |
| Motor mixing | Cap input throttle at 1800. At 250 Hz, apply `1.024 × (throttle ± roll ± pitch ± yaw)` to four 12-bit duty values. Clamp to 1000–1999 ticks, then enforce 1180 tick armed idle; disarmed/low throttle outputs use a safe 1000 µs pulse. | M1 front left `+R−P+Y` → D1; M2 front right `−R−P−Y` → D2; M3 rear right `−R+P+Y` → D3; M4 rear left `+R+P−Y` → D0. A saved permutation can change connectors only. |
| Accessories | Scan multiple I²C addresses when disarmed, drive one 50 Hz servo on an available A2 D7–D10 signal, read NMEA 9600 or optionally configure bundled UBX GPS at 10 Hz, drive available GPIO and an HT16K33 I²C matrix. | 2D reference wiring, AP/WebApp `/io` and Python methods share these commands. GPS telemetry is read only; no position hold or GPS-based motor command is implemented. |
| Safety and monitoring | On RC timeout, source change, IMU failure, loop stall or explicit disarm, send safe outputs and reset PID. Block I²C bench operations and pin changes during armed output. | Use prop-off motor order testing, live source/Hz readings and physical measurements to check signs, pulse widths, IMU orientation and timing before a restrained trial. |

The supplied original sketch sent Wi-Fi receiver values directly and auto-ran ESC calibration at boot. Here, the local lock and source watchdog gate Web/AP/Python frames, and the guarded bench command runs ESC calibration only on deliberate request. The supplied motor mixing signs and duty scaling are retained in the armed path.
